# 💰 Bolso em Dia

A web system for personal financial management, developed to help users organize their income, expenses, worked days, extra services and financial projections.

This project was created during the Systems Development course at SENAI and is still under development as new concepts and features are implemented.

## ✨ Features

- User registration
- Login system
- Income registration
- Expense registration
- Extra service registration
- Worked days tracking
- Collected packages tracking
- Current balance calculation
- Monthly and annual financial projections
- Monthly income overview
- Weekly history
- Annual reports
- User data separation
- Responsive interface
